An automatic coffee machine with four beverage options and three coffee strengths. The process is implemented as sequential control using Sequential Function Chart (SFC) and Structured Text (ST), with an HMI for user interaction and generalized actuator logic for process management.

Tools: CODESYS V3.5 SP20
